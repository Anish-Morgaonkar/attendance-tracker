Python Student Attendance Tracker

Project Overview
I made this simple python program to help teachers take attendance on a computer instead of using paper registers. You just add the student names, enter the date, and mark them present or absent. I used a python dictionary to store everything, where the name is the key and their attendance is saved in a list.

Features
- Add any number of student names at the start
- Enter today's date
- Mark a student present or absent
- Check the full attendance history of the class

Technologies and tools used
- Python 3
- VS Code and Terminal
- Core python concepts like lists and dictionaries

Steps to install and run the project
1. Download my code to your laptop.
2. Make sure python is installed.
3. Open terminal and go to the folder where you downloaded it.
4. Type python attendance_tracker.py and press enter.

Instructions for testing
Run the file and add some test names like Rahul and Amit. Type quit when you are done adding names. Then it will ask for the date, just type today's date. Choose option 2 from the menu to mark someone present, and option 1 to see the final record. Choose option 4 to exit.
