Problem Statement:
Taking attendance on paper takes too much time in class. It is also hard to count the total present days at the end of the month manually. We need a simple digital tool to record this quickly.

Scope of the project:
This is a basic terminal based python script. It does not use any heavy databases. It just uses basic python dictionaries and lists to store the attendance data in memory while the program is running.

Target Users:
- College teachers taking daily classes
- Lab teachers checking attendance for practicals
- Club coordinators taking roll call

High-level features:
- Add student names directly in the terminal
- Update the date anytime
- Mark students present or absent
- Show the full history of the whole class on the screen
